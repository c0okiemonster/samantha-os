# Wake Word Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an opt-in "Hey Samantha" wake word mode that uses browser-side VAD + the existing Faster-Whisper STT for keyword matching, with zero new dependencies, alongside the existing push-to-talk.

**Architecture:** A new `WakeWord` IIFE in the visual shell monitors the existing `micAnalyser` for speech via amplitude thresholds (VAD). On detected speech, it auto-calls `startRec()` / `stopRec()` (existing recording functions) and sends audio with `source: 'wake'`. The orchestrator's WS handler checks whether the STT transcript starts with a "samantha" wake prefix — if yes, strips the prefix and processes normally; if no, discards silently. A new per-connection `wake_mode` flag tracks whether the client has wake enabled. PTT (space bar) always works, sends `source: 'ptt'`, and bypasses prefix filtering.

**Tech Stack:** Python 3 + FastAPI (existing), vanilla JS (existing `MediaRecorder` + `AnalyserNode`), `pytest` (existing). No new libraries or services.

**Spec:** `docs/superpowers/specs/2026-04-06-wake-word-design.md`

```python
"""Wake word prefix detection. Pure function, no I/O."""
from __future__ import annotations


# Longest prefixes first so "hey samantha" matches before bare "samantha".
WAKE_PREFIXES = [
    "hey samantha",
    "okay samantha",
    "ok samantha",
    "hi samantha",
    "samantha",
]


def detect_wake_prefix(text: str) -> tuple[str | None, str]:
    """Check if `text` starts with a known wake prefix.

    Returns (matched_prefix, remainder). If no match: (None, text).
    The matched_prefix is always lowercase. The remainder has leading
    whitespace and common punctuation stripped.
    """
    lower = text.lower().strip()
    if not lower:
        return None, text.strip()

    for prefix in WAKE_PREFIXES:
        if lower.startswith(prefix):
            remainder = text[len(prefix):].lstrip(" ,.-!?")
            return prefix, remainder

    return None, text
```

```js
    // ─── Wake Word module ────────────────────────────────────────────
    const WakeWord = (() => {
      let enabled = false;
      let speaking = false;
      let silenceStart = 0;
      let speechStart = 0;
      let animFrame = null;

      const THRESHOLD = 15;    // RMS amplitude 0-128
      const SPEECH_MS = 300;   // speech must exceed threshold this long
      const SILENCE_MS = 1500; // silence must last this long to stop recording

      function monitor() {
        if (!enabled) return;
        // Suppress while Samantha is speaking to prevent feedback loop
        if (mood === 'speaking') {
          speechStart = 0;
          silenceStart = 0;
          speaking = false;
          animFrame = requestAnimationFrame(monitor);
          return;
        }
        if (!micAnalyser) {
          animFrame = requestAnimationFrame(monitor);
          return;
        }
        const data = new Uint8Array(micAnalyser.fftSize);
        micAnalyser.getByteTimeDomainData(data);
        let sum = 0;
        for (let i = 0; i < data.length; i++) {
          const v = (data[i] - 128) / 128;
          sum += v * v;
        }
        const rms = Math.sqrt(sum / data.length) * 128;

        if (rms > THRESHOLD) {
          silenceStart = 0;
          if (!speaking && !recording) {
            if (!speechStart) speechStart = Date.now();
            if (Date.now() - speechStart > SPEECH_MS) {
              speaking = true;
              audioSource = 'wake';
              startRec();
            }
          }
        } else {
          speechStart = 0;
          if (speaking && recording) {
            if (!silenceStart) silenceStart = Date.now();
            if (Date.now() - silenceStart > SILENCE_MS) {
              speaking = false;
              silenceStart = 0;
              stopRec();
            }
          }
        }
        animFrame = requestAnimationFrame(monitor);
      }

      async function enable() {
        if (enabled) return;
        if (!micAnalyser) await initAudio();
        if (!micAnalyser) {
          console.warn('🎤 WakeWord: mic not available');
          return;
        }
        enabled = true;
        speaking = false;
        speechStart = 0;
        silenceStart = 0;
        monitor();
        localStorage.setItem('samantha.wake.enabled', 'true');
        if (ws && ws.readyState === 1) {
          ws.send(JSON.stringify({event: 'wake_mode', enabled: true}));
        }
        console.log('🎤 WakeWord enabled');
      }

      function disable() {
        enabled = false;
        speaking = false;
        if (animFrame) { cancelAnimationFrame(animFrame); animFrame = null; }
        localStorage.setItem('samantha.wake.enabled', 'false');
        if (ws && ws.readyState === 1) {
          ws.send(JSON.stringify({event: 'wake_mode', enabled: false}));
        }
        console.log('🎤 WakeWord disabled');
      }

      function isEnabled() { return enabled; }

      async function restoreFromStorage() {
        if (localStorage.getItem('samantha.wake.enabled') === 'true') {
          await enable();
        }
      }

      return { enable, disable, isEnabled, restoreFromStorage };
    })();
```
